# Quest map tags (`m` field): sources

Each tag needs two sources (CLAUDE.md sourcing rules). Source 1 is the
arcraiders.wiki Location field (the Quests table, or the quest's own page when the
table cuts off). Source 2 is listed per quest. Researched Oct 18, 2026, patch 2.1.0.

## Dam Battlegrounds (27 quests)

Wiki Location includes Dam Battlegrounds for all of these.

Objectives name Dam Battlegrounds / The Dam directly (MetaForge/ArcTracker quest text):
greasing-her-palms, what-we-left-behind, medical-merchandise, eyes-in-the-sky,
a-symbol-of-unification, the-majors-footlocker, back-on-top,
source-of-the-contamination, our-presence-up-there, a-rising-tide, taking-stock,
the-league

ArcTracker quest page lists Dam Battlegrounds as a map:
a-better-use, water-troubles, paving-the-way, flickering-threat

Walkthrough guide places it on Dam Battlegrounds:
- straight-record, echoes-of-victory-ridge: Shacknews, "Where is Victory Ridge" (on Dam Battlegrounds)
- keeping-the-memory: Dexerto walkthrough
- a-balanced-harvest: Destructoid walkthrough
- untended-garden: GamesFuze walkthrough
- celestes-journals: GamesFuze walkthrough
- broken-monument: Dexerto walkthrough
- dormant-barons: FDayTalk (Baron husks on Dam Battlegrounds, Spaceport, Blue Gate)
- a-new-type-of-plant: GamesFuze walkthrough (Old Battleground, Dam)
- a-toxic-trail: Dexerto walkthrough
- to-the-skies: KeenGamer walkthrough (Gondola Prototype near Red Lakes, Dam)

Several of these also take place on other maps (wiki lists them). Those maps get
tagged in their own passes.

## Map-condition quests (`c` field, Oct 19)

- boarding-the-frigate, disrupting-the-frigate: c = ["ARC Frigate"]. Objectives are all
  on the Frigate; games.gg calls it a map condition; MetaForge's event schedule lists
  "ARC Frigate" slots (Oct 19 sample: Blue Gate, Buried City, Dam, Pendola Pass, Spaceport).
- nothing-gained: c = ["Matriarch", "Harvester"]. Objectives: destroy a Matriarch and
  a Queen. Prima Games: the Matriarch spawns during the Matriarch event and the Queen
  guards the Harvester event; MetaForge's schedule lists both (Blue Gate, Dam, Spaceport).

## Open questions

These three stay untagged on purpose. They depend on a live map condition rather than
a map, so the site lists them under "Needs a map condition":
- boarding-the-frigate, disrupting-the-frigate: the ARC Frigate is a map condition.
  games.gg says it can show up on the six outdoor maps (not Stella Montis); no second
  source yet.
- nothing-gained: Matriarch and Queen kills. The Matriarch only spawns during a
  Matriarch event (Prima Games: Dam Battlegrounds, Spaceport); the Queen guards the
  Harvester event.
- Possible later: the arcmaps.com event feed (used by the Project's arc_timers.py)
  lists which maps currently host each condition.
